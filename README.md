# K-Tech Vault Atlas — Landing Page

フォルダと HUB（MOC）の地図をスキャンして、入口から辿れるようにするプラグインの LP です。

- ファイルが増えた人、使い方が分からない人の両方を正面に書いています
- 日本語 / English は右上で切り替え（`index.html` 1 枚）
- 機能の説明用画像は `images/` の JPEG です（OG は `og.jpg`）

フレームワークは使いません。静的ファイルだけです。

公開: https://k-tech-vault-atlas-lp.vercel.app/
